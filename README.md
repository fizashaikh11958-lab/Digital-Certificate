# Certificate System (Streamlit)

Create certificates (PNG/PDF), generate many at once (ZIP), and verify a certificate by its ID.

## Run locally
    pip install -r requirements.txt
    streamlit run app.py

## Host on Streamlit Community Cloud (free)
1. Upload app.py, requirements.txt and packages.txt to a GitHub repository.
2. Go to https://share.streamlit.io -> Create app -> choose the repo -> Main file path: app.py -> Deploy.

Do NOT upload the old Flask app.py (the one ending with app.run). Replace it with this file.
